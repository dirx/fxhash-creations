## Still D

Real-time deterministic svg image, flexible size, 2025

Grab it @ https://www.fxhash.xyz/generative/slug/still-d

### About

<img src="./public/preview.png" align="right" width="50%" style="margin: 0 20px 20px 20px" />

Way too many adhesive dots to stick while also keeping an eye on the flow field.

Features:

- dotSize (0.7 - 0.9) - default dot size
- gridSize (21 - 63, step: 7) - number of grid rows & columns
- palettes (2 - 8) - list of colors picked from 160 4-color palettes
- attractors(3 - gridSize basis, steps: 7) - number of attractor points used for the flow field

Shortcuts & interactions:

- `h` to toggle help
- `p` to download as png
- `s` to download as svg
