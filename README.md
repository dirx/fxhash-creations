## Still A

Real-time deterministic svg image, flexible size, 2025

Grab it @ https://www.fxhash.xyz/generative/slug/still-a

### About

<img src="./public/preview.png" align="right" width="50%" style="margin: 0 20px 20px 20px" />

A rippled SDF composed of italicized shapes, duplicated into layered contours with neon colors, and rendered as polygons in an SVG.

Features:

- gap (0 - 64, step: 8) - extra shape gap
- italic (-45 - 45, step: 3) - shape italic angle
- resX (32 - 1024, step: power of 2) - horizontal resolution
- resY (32 - 1024, step: power of 2) - vertical resolution
- palettes (2 - 8 selections from 0 - 159) - color palette ids
- rects (0 - 8) - number of rectangles
- circles (0 - (8 - rects)) - number of circles
- triangles (0 - (8 - rects - circles)) - number of triangles
- freqX (0 - 16) - horizontal ripple frequency
- freqY (0 - 16) - vertical ripple frequency
- ampX (0 - 32) - horizontal ripple amplitude
- ampY (0 - 32) - vertical ripple amplitude

Shortcuts & interactions:

- `h` to toggle help
- `p` to download as png
- `s` to download as svg
